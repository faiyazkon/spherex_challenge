How to spot discoveries:
  • Fast Proper Motion: Look for a source shifting position back-and-forth between epochs (like WISE 0855 or Barnard's Star).
  • Variable Stars: Look for an object staying fixed in place but rhythmically brightening or fading in flux.
  • Transient Outbursts: Look for an object present in only one epoch.
